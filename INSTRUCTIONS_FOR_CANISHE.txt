STEP 3: CLONE AND RUN THE STARTER PROJECT LOCALLY ON WINDOWS 11
================================================================================

Once the codebase is pushed to GitHub, open your Command Prompt or PowerShell:

1. Clone the project:
   git clone https://github.com/<YOUR-GITHUB-USERNAME>/OmniQuery-AI.git
   cd OmniQuery-AI

2. Start the PostgreSQL Database with pgvector:
   docker-compose up -d

3. Set up your Python Virtual Environment on Windows:
   python -m venv .venv
   .\.venv\Scripts\activate
   pip install -r requirements.txt

4. Configure Environment Variables:
   copy .env.example .env

5. Run the FastAPI Backend:
   uvicorn app.main:app --reload --port 8000
   -> Open Swagger Documentation in your browser: http://localhost:8000/docs

6. Run the Interactive Streamlit Web UI (in a new terminal):
   .\.venv\Scripts\activate
   streamlit run ui/streamlit_app.py --server.port 8501
   -> Open Chat UI in your browser: http://localhost:8501
